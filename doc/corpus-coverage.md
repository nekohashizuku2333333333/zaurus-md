# Markdown 语料覆盖记录

输入文件是 `tests/corpus/markdown-corpus.md`，原件未修改。
采用 MD4C 0.5.3 解析 CommonMark/GFM，由本项目转换成 Qt/E 2.3.2 富文本。
这不是完整的 Markor 功能对等声明，也不包含 Android 的 WebView 渲染引擎。

## 本轮覆盖

| 语料章节 | 当前处理 |
| --- | --- |
| 1.1–1.3 标题、段落、换行 | ATX 空白与结尾井号、Setext、多行段落、软换行、两空格和反斜杠硬换行 |
| 1.4 引用 | 嵌套、lazy continuation、引用中的列表和代码 |
| 1.5 列表 | 三种无序标记、`.`/`)` 有序标记、非 1 起始、嵌套、松散和紧凑列表 |
| 1.6–1.8 代码和强调 | 围栏匹配、缩进代码、代码空白、成组反引号、嵌套强调、词内下划线规则 |
| 1.9–1.10 链接和图片 | 引用定义、大小写匹配、标题、括号 URL、自动链接、图片 alt；相对图片以当前文件为上下文 |
| 1.11–1.13 分割线、HTML、实体 | CommonMark 分割线；原始 HTML 显示为转义文本；HTML 实体解码后重新转义 |
| 2.1–2.4 GFM | 表格列对齐和列数处理、转义竖线、嵌套删除线、嵌套任务、裸 URL 和邮箱 |
| 3.1、3.7 数学和语言围栏 | 数学内容保留公式源码，不参与强调解析；Mermaid/diff 等按代码块显示 |
| 4 边界 | UTF-8、BOM、CR/LF/CRLF、NUL 替换、100KB 长行、深度限制、随机标记组合 |

## 尚未实现

- 脚注语义：不生成脚注编号或回跳；MD4C 可能按普通引用链接处理其定义。
- 高亮、上下标、定义列表、特殊 callout、YAML 元数据、emoji 短代码扩展。
- 数学排版、Mermaid 图形生成、代码语言语法着色。
- 外部链接启动浏览器、远程图片下载；当前预览支持本地图片和任务链接交互。
- 字体没有的 emoji、复杂文字塑形和字形不能由解析器补足。

Markdown 源文件不会被渲染过程修改。上面的扩展仍可在编辑模式中查看和编辑。

## 边界与验证

本轮结果：223 次本地执行通过内存检查，223 份 ARM 输出与本地逐字节一致；
另有 20 项实际 Qt2 包装层测试通过。最终 IPK 的三层归档通过远端旧 tar 读取检查。

1. 1.6 节的未闭合代码围栏会影响整份文件后面的语法状态，之后出现的兼容围栏
   还可能将它关闭。因此同时测整份文件和按编号标题分开的 35 个片段，不能仅凭
   整份文件中某节显示成代码就判断该节不受支持。
2. 本地 `sh scripts/test-corpus.sh` 使用 ASan、UBSan 和 LeakSanitizer，验证语义断言、
   输出标签配对、任务偏移、随机用例和体积边界，并记录输出。
3. 将 `test-runtime/corpus-cases` 同步至 SDK 主机后运行
   `sh scripts/test-arm-corpus.sh`，用 ARM QEMU 逐字节对照本地输出。
4. `sh scripts/test-remote.sh` 另外测试真实 Qt2 QString 包装和任务回写。
5. 预览限制为输入 4 MiB、输出 8 MiB、嵌套深度 64。超限停止预览并报告错误，
   编辑文本保持完整；这是为了避免旧 Qt 富文本布局处理无限嵌套。
6. 这些测试没有运行真机 framebuffer。表格、中文代码字体、长代码行横向滚动、
   触摸和放大模式仍需在 640×480 设备上手测。
